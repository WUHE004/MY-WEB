# 库存盘点操作指引

> 功能位置：运营操作台 → 库存盘点（紫色入口）
> 适用场景：按货架浏览库存、搬运商品、校准库存差异

---

## 一、功能简介

库存盘点以**货架分区 → 货架 → 层**三级结构浏览全部在库商品，支持：

- **搬货**：商品换货架后，三级选择更新货架号
- **校准**：发现实物数量与系统不符时提交校准待办，到管理栏处理后消除

系统数量（黄色块）= 入库合计 − 已售合计 + 已退合计。

---

## 二、页面结构（三级钻取）

```
┌──────────────────────────────┐
│ ← 库存盘点                    │
│ [A区] [B区] [C区] [袋区] [未分区]  ← 分区按钮条（置顶, 左右滑动）
├──────────────────────────────┤
│ 面包屑: A区 > A1 货架 > 第 2 层  │
│                              │
│ 视图1: 货架卡片网格            │
│   [A1 货架] [A2] [A3] [A4]   │
│   12款商品  8款   0款   5款    │
│                              │
│ 视图2: 层列表（点货架后）       │
│   [第1层] [第2层] ... [第5层] │
│    4款      3款         0款   │
│                              │
│ 视图3: 商品卡片（点层后）       │
│   [图] F34 韩版卫衣           │
│        进价¥9.8 厂家 小鱼家    │
│        入库 2026/09/01       │
│        110码·3  120码·2      │
│        [搬货] [校准]          │
└──────────────────────────────┘
```

### 分区按钮条

- 显示**所有分区**：货架设置中的排（A/B/C/袋...）∪ 商品中实际出现的排，末尾固定"未分区"
- 入库登记新增货架分区后，下次打开盘点页自动出现新按钮
- 按钮条**置顶固定**，上下滚动浏览商品时始终可见；分区多时**左右滑动**查看
- 面包屑（分区 > 货架 > 层）可点击回退上级

### 商品卡片

参考管理栏总表样式缩小版：图片、编号、名称、进价、厂家、入库日期、货架号、各尺码数量（黄色块，红色块=负库存异常）。

---

## 三、搬货（更换商品货架）

1. 在商品卡片点 **「搬货」**
2. 弹窗顶部显示当前货架号，下方**三级级联选择**（一排 / 货架号 / 层），与入库登记同款
   - 每次打开自动同步最新的货架设置（含入库登记新加的货架）
   - 已有货架号自动回填
3. 三级选齐后点 **「保存新货架位置」**
4. 更新该编号**全部入库记录**的货架号，管理栏总表同步生效

---

## 四、库存校准（差异待办）

发现实物数量与系统不符时：

1. 在商品卡片点 **「校准」**
2. 弹窗列出每个尺码的**现有数量**（黄色块），在输入框填**校准数量**（实际数出来的数）
   - 输入时实时显示差异（绿 +N / 红 -N）
   - 不填的尺码视为不变
3. 点 **「提交校准」**，生成待办记录

### 到管理栏处理

- 校准提交后，**桌面端管理栏**左上角标题右边显示待办：
  - 单条：直接显示文字，如 `校准 K25 180码 6→5`
  - 多条：显示 `库存校准待办 N`，点击展开下拉列表
- **点击待办条目** → 搜索框自动填入该商品编号并筛选（自动切到总表视图、回到页面顶部），可查看该商品的入库/售出/退货明细定位差异原因
- 处理完（补录/修正对应记录）后点条目右侧 **×** 删除该待办

> 注意：校准**只生成待办提醒，不直接修改库存数字**。请根据差异原因补录售出/退货/入库记录来修正库存。

---

## 五、注意事项

1. **未分区**：无货架号或货架号无法解析的商品（约 200+ 款历史数据）归入"未分区"，点分区按钮直接显示商品列表
2. **层固定 1-5**：无商品的层按钮置灰不可点
3. **权限**：需要管理员或操作员身份（API 已加鉴权）
4. **数据实时**：每次打开页面重新聚合（入库 − 已售 + 已退），搬货后立即生效
5. **负库存**：某尺码显示红色（数量 < 0）说明数据异常（售出多于入库），建议优先处理
